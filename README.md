# Python Sales Data Analysis

A portfolio-ready Data Analyst project using **Python, Pandas, NumPy and Matplotlib**.  
It analyzes a synthetic retail orders dataset to understand revenue, product performance, regional sales, discount impact and monthly trends.

## Project objectives
- Clean and validate raw order data.
- Calculate net sales after discounts.
- Perform exploratory data analysis (EDA).
- Identify top products, categories, regions and sales channels.
- Export summary tables and a monthly sales chart.

## Tools
Python 3.10+, Pandas, NumPy, Matplotlib

## How to run
1. Download or clone this project.
2. Open a terminal in the project folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the analysis:
   ```bash
   python src/analysis.py
   ```
5. Check the generated CSV summaries and chart in the `outputs/` folder.

## Key business questions
1. What is the total net sales generated?
2. Which products and categories generate the most revenue?
3. Which regions contribute the most sales?
4. How do sales change month by month?
5. What is the impact of discounts on net sales?

## Dataset
The included dataset is **synthetic and created for learning/portfolio demonstration**. It contains 1,200 order records across 2025. It does not represent a real company or customer data.
